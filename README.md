# Mundo de Wumpus - Inteligencia Artificial

Proyecto académico para implementar un agente inteligente capaz de explorar el Mundo de Wumpus mediante reglas lógicas.

## Objetivo

Desarrollar un agente que interprete percepciones del entorno, evite peligros, encuentre el oro y regrese al punto inicial de manera segura.
